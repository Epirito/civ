# Visualization

This note describes how `EconomicSimPage.tsx` and `canvas.ts` present the
economic simulation state. For engine-level market rules, see
`MARKET_SIM_QUIRKS.md`.

## Canvas

- The canvas uses a uniform cell background.
- Population is drawn as a Consumer-colored circle.
- Factories are drawn as Producer-colored rectangles.
- Logistics-owned widget inventory is summed across Logistics agents and drawn
  as a small gear marker in the cell corner with a count.
- Current-turn transports are drawn as Logistics-colored lines from source to
  destination.
- The flame control toggles a heatmap of Logistics' modeled marginal widget
  value by destination cell. Finite values are normalized against the highest
  finite modeled value in the current snapshot; unknown infinite values render at
  maximum intensity.
- The rabbit control runs one simulation step per animation frame, which is the
  fastest mode that still gives the browser a chance to render each state.
- Hovering a cell outlines it and updates the readout.

## Readouts

The hover readout shows per-agent balances for the selected physical cell:

- widgets
- factories
- population

If Logistics has a modeled marginal widget value for the selected cell, the
readout shows it even when the heatmap is off. Unknown optimistic values display
as `unknown`.

It also shows the average trade price for that cell from the most recent turn,
when the cell had trade activity. If the cell had no trade, that line is
omitted.

When the selected cell had orders in the most recent turn, the readout also
shows average bid and ask prices with submitted quantities.

The page logs the current turn to the browser console whenever the turn number
changes.

Money is generated by population and destroyed by transport costs, while widgets
are generated by factories. Agent totals are still shown because they describe
current ownership rather than conservation.
